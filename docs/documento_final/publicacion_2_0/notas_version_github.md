# Versión pública 2.0

Texto para la publicación de GitHub del repositorio vivienda-espana-evidencia (`gh release create v2.0 … --notes-file`; docs/tareas_autor.md, punto 7). Va sin cifras: todas están en [publicacion/documento_final/documento_final.md](../../../publicacion/documento_final/documento_final.md) y [publicacion/cifras_clave.csv](../../../publicacion/cifras_clave.csv), cada una con su capa, su fecha y su ficha.

---

## Qué es
- **Una base de evidencia independiente y reproducible sobre la vivienda en España**: déficit y necesidad de vivienda 2026-2035, precios de compra y alquiler triangulados, diferencias territoriales, atribución por factores y periodos (V8), diseños pre-registrados (V9), base de datos única con atlas y web (V10-V12) y, nuevo en la 2.0, un **documento final** que reúne lo que permiten decir V15 a V18: réplicas de la literatura, auditoría de afirmaciones y medidas, y una mejor estimación por factor rotulada como juicio experto.
- **Cada resultado lleva una capa de evidencia** (C1 hecho, C2 cota, C3s restricciones de signo, C4 exploratorio). Ningún resultado está en C3: no hay lenguaje causal.
- **Por dónde empezar:** el resumen ejecutivo de dos páginas del [documento final](../../../publicacion/documento_final/resumen_ejecutivo.md) y [LEEME_PRIMERO.md](../../../LEEME_PRIMERO.md).

## Qué cambia respecto a la 1.0
- Documento final (publicacion/documento_final/) y su resumen en la web y en consulta/.
- Ninguna cifra publicada cambia de valor ni de capa; se añaden cifras nuevas de V15-V18 (ERRATA.md).
- Los datos de la AEAT se redistribuyen (series, variables de la capa pública y tablas derivadas), con su atribución.
