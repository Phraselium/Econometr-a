## Descomposición histórica: viable, pero solo como contabilidad descriptiva (C4)

Con un θ no identificado no se puede repartir la variación «por factores». La propuesta es esta:

1. **Partir de las identidades, no del θ estimado.** Para cada CCAA y cada periodo (2014T1-2019T4, 2020T1-2022T2, 2022T3-último) se reporta Δy observado = Σ_k θ_k·Δx_k + residuo. Se calcula para los tres estimadores de la triangulación (MG_dm con θ común, PMG_dm y CS-DL), y para cada uno se da el rango de cada componente.
2. **Mostrar el residuo siempre como una barra más**, con su porcentaje sobre Δy. Si |residuo| > |Δy|/2, o si los signos de las contribuciones difieren entre estimadores, la celda se marca «no atribuible».
3. **No usar θ_i por región** (signo inestable y sin cointegración demostrada). Como mucho, añadirlos en un anexo como sensibilidad.
4. **Rótulo obligatorio:** «contabilidad con coeficientes no confirmados (H7 no confirmada); asociación, sin lectura causal; magnitud como rango».
5. **Resultado previsible:** un residuo dominante. Ese hallazgo debe publicarse tal cual.
